# Deploy ke Cloudflare Pages (Next.js)Dokumen ini menuntun Anda menjalankan proyek Next.js ini di Cloudflare Pages menggunakan Next on Pages.## Ringkasan- Target: Cloudflare Pages (Workers runtime)- Build command: `npx @cloudflare/next-on-pages@latest`- Output directory: `.vercel/output/static`- Node.js compatibility: aktif (otomatis oleh Next on Pages / tambahkan `--compatibility-flag=nodejs_compat` saat preview)## Prasyarat- Akun Cloudflare dan akses membuat Project Pages- Node.js 18/20 di mesin lokal (untuk preview via CLI)- Login Wrangler CLI: `npx wrangler login`## 1) Konfigurasi skrip npmSudah ditambahkan skrip berikut di `package.json`:- `npm run build:cf`  → Build untuk Cloudflare Pages (Next on Pages)- `npm run dev:cf`    → Preview lokal dengan Wrangler- `npm run deploy:cf` → Deploy via CLI ke Cloudflare Pages> Catatan: Skrip ini memakai `npx` sehingga tidak wajib menambah devDependency.## 2) Variabel Lingkungan (ENV)Set di Pages → Project → Settings → Environment variables & Secrets.Minimal yang perlu diisi agar aplikasi berjalan:- `JWT_SECRET` → kunci JWT Anda (wajib)- `NEXT_PUBLIC_APP_URL` → URL publik aplikasi (mis. `https://<project>.pages.dev` atau domain kustom)- `NEXT_PUBLIC_BASE_URL` dan `BASE_URL` → samakan dengan URL publik di atas jika digunakanJika memakai integrasi bank (sandbox/produksi), isi juga:- BRI: `BRI_BASE_URL`, `BRI_CLIENT_ID`, `BRI_CLIENT_SECRET`, `BRI_API_SECRET`, (opsional) `BRI_PARTNER_ID`- BCA: `BCA_CLIENT_ID`, `BCA_CLIENT_SECRET`, `BCA_API_SECRET`, `BCA_BASE_URL`, `BCA_CHANNEL_ID`WiFi automation tidak didukung di Cloudflare (Workers tidak menjalankan scheduler Node). Pastikan:- JANGAN set `ENABLE_WIFI_AUTOMATION` ke `true` pada Pages- Biarkan kosong atau `false`Rujukan kunci lihat: `.env.local.example` dan `.env.production`. Jangan commit nilai rahasia ke repo.## 3) Deploy via Git (disarankan)1. Hubungkan repo ini ke Cloudflare Pages2. Framework preset: `Next.js`3. Build command: `npx @cloudflare/next-on-pages@latest`4. Build output directory: `.vercel/output/static`5. Tambahkan Environment Variables seperti di atas (untuk Production/Preview sesuai kebutuhan)6. Simpan dan trigger buildSetelah sukses, situs tersedia di `https://<project>.pages.dev`. Tambahkan domain kustom bila perlu.## 4) Deploy via CLI (opsional)Untuk build lokal dan deploy manual:```shnpm cinpm run build:cfnpx wrangler pages deploy .vercel/output/static --project-name <nama-project-pages>```Preview lokal (development):```shnpm run dev:cf# atau manual:# npx wrangler pages dev .vercel/output/static --compatibility-flag=nodejs_compat```Windows 11 (tanpa WSL):- Pastikan Git for Windows terpasang (agar `bash` tersedia di PATH)- Jalankan PowerShell sebagai user biasa:  - `.\\server-docs\\deploy-cloudflare-windows.ps1` → build + preview lokal  - `.\\server-docs\\deploy-cloudflare-windows.ps1 -Deploy -ProjectName <nama-project>` → deploy ke Pages## 5) Catatan kompatibilitas- Scheduler/cron (`node-cron` di `src/lib/wifi-scheduler.ts`) tidak berjalan di Workers. Biarkan `ENABLE_WIFI_AUTOMATION` tidak aktif pada Pages. Bila butuh penjadwalan, gunakan Cloudflare Cron Triggers pada Worker terpisah.- Modul `puppeteer` tidak didukung di Workers runtime. Pastikan fitur terkait tidak dipanggil di Pages.- Kriptografi: kode memakai `crypto` Node (HMAC/sha256) yang dikompabilitaskan oleh Next on Pages dengan `nodejs_compat`. Jika menemui kendala, saya bisa memigrasikan ke Web Crypto.## 6) Verifikasi- Cek log build di Cloudflare Pages → Deployments- Akses `/login` dan `/dashboard` untuk memastikan middleware berfungsi- Uji endpoint API penting: contoh `/api/connection-test`## 7) Troubleshooting cepat- Build error terkait modul Node: pastikan menggunakan build command Next on Pages seperti di atas, dan jangan set `ENABLE_WIFI_AUTOMATION=true`- 5xx saat call BRI/BCA: periksa ENV kredensial dan izin IP/WAF di sisi bank- CSP/Content Security Policy: edit di `next.config.ts` bagian `headers()` bila ada blokir koneksi eksternalButuh bantuan set proyek Pages atau menyesuaikan fitur agar 100% kompatibel dengan Workers?
